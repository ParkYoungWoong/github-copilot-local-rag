# 로컬 RAG 기본 환경

문서 폴더를 내 PC에서 RAG(검색 증강 생성)로 만들고, 어느 프로젝트에서든 Copilot에게 문서 내용을 물어볼 수 있게 하는 기본 환경입니다.
PC마다 한 번 설치하면, 그다음부터는 프로젝트를 열고 Copilot에게 요청만 하면 됩니다.
[GitHub Copilot 업무 비서 만들기](https://www.heropy.dev/p/PgnSNw)의 '로컬 RAG'에서 사용합니다.

준비물은 VS Code와 GitHub Copilot입니다. Python과 Ollama는 설치할 때 Copilot이 확인하고, 없으면 설치를 도와줍니다.

> Copilot은 이 폴더의 [AGENTS.md](AGENTS.md)를 읽고 진행합니다.

## 사용 순서

모든 일은 VS Code에서 폴더를 열고, 채팅 입력창에 아래 요청을 입력하는 것으로 끝납니다. 에이전트는 Agent로 둡니다.
아래에서 '키트 폴더'는 이 저장소를 받은 폴더(ZIP으로 받으면 `github-copilot-local-rag-main`, 반입용으로 복사하면 `local-rag`)를 말합니다.

| 할 일 | 여는 폴더 | Copilot에게 할 요청 |
| --- | --- | --- |
| 처음 설치(PC마다 한 번) | 키트 폴더 | `설치해 줘` |
| 내 프로젝트에 적용 | 내 프로젝트 | `/local-rag 이 프로젝트에 적용해 줘` |
| 활용 예제 만들기 | 예제를 만들 폴더 | `/local-rag 이걸 활용하는 팀 FAQ 예제를 만들어 줘` |
| 문서에서 찾기 | 아무 프로젝트 | `/local-rag 출장 일비 기준을 찾아 줘` |
| 상태 점검 | 아무 프로젝트 | `/local-rag 점검해 줘` |

1. 저장소 페이지에서 `Code > Download ZIP`을 눌러 압축 파일을 받고 압축을 풉니다. 압축을 푼 `github-copilot-local-rag-main` 폴더가 키트 폴더이며, 홈 폴더 아래에 두는 것을 권합니다.
1. VS Code의 `파일 > 폴더 열기`로 압축을 푼 폴더를 열고 `설치해 줘`라고 요청합니다. Copilot이 설치 계획을 먼저 보여 주고 확인을 받은 뒤 설치합니다.
1. 설치가 끝나면 VS Code를 완전히 종료했다가 다시 엽니다.
1. 내 프로젝트를 열고 새 대화에서 `/local-rag 이 프로젝트에 적용해 줘`라고 요청합니다. Copilot이 문서 폴더를 찾아 RAG로 만들고, 프로젝트 지침에 사용법을 적어 둡니다.

## 사내망으로 가져가기

인터넷이 막힌 사내망 PC에는 설치 재료를 미리 받아서 외장 드라이브로 가져갑니다. 한 번 가져가면 사내망 안의 어느 프로젝트에서든 다시 쓸 수 있습니다.

1. 인터넷이 되는 PC에서 키트 폴더를 VS Code로 열고 `반입 준비해 줘`라고 요청합니다. 사내 PC의 운영체제를 물으면 답합니다. Ollama 설치 파일, 임베딩 모델, Windows용 Python 설치 파일 등 약 2.5GB를 키트 폴더 안의 `offline` 폴더에 받으며, 이 PC에는 아무것도 설치하지 않습니다.
1. 외장 드라이브를 연결하고 `E 드라이브에 반입용으로 복사해 줘`처럼 요청합니다. 키트 폴더가 외장 드라이브의 `local-rag` 폴더로 복사되며, PC마다 새로 만드는 파일(가상 환경, 설정, 색인)은 빼고 복사합니다.
1. 사내 PC에서 외장 드라이브의 `local-rag` 폴더를 VS Code로 열고 `설치해 줘`라고 요청합니다. Copilot이 폴더를 홈 폴더로 복사한 뒤, 인터넷 없이 설치합니다.

색인은 사내 PC에서 사내 문서로 새로 만듭니다. 외부에서 만든 색인을 가져가야 하면 복사를 요청할 때 "색인도 함께"라고 말합니다. 색인에는 문서 내용 조각이 들어 있으니 반출 규정을 확인합니다.

사내망에서도 Copilot은 GitHub에 접속할 수 있어야 합니다. RAG의 색인과 임베딩은 PC 안에서만 동작합니다.

## 사용 예

| 할 일 | 요청 |
| --- | --- |
| 폴더를 RAG로 만들기 | `/local-rag docs 폴더 파일 모두를 RAG로 만들어 줘` |
| 질문 | `/local-rag [찾을 내용]을 찾아 줘` |
| 목록 확인 | `/local-rag 목록 보여 줘` |
| 파일 하나만 다시 반영 | `/local-rag docs 컬렉션에서 [파일 이름]을 다시 인덱싱해 줘` |
| 조건에 맞는 문서만 갱신 | `/local-rag docs 컬렉션에서 이름이 [단어]로 시작하는 문서만 갱신해 줘` |
| 컬렉션 갱신(바뀐 파일만 처리) | `/local-rag docs 컬렉션을 갱신해 줘` |
| 처음부터 다시 만들기 | `/local-rag docs 컬렉션을 처음부터 다시 만들어 줘` |
| 문서 폴더를 옮겼을 때 | `/local-rag docs 폴더를 [새 위치]로 옮겼어` |
| 검색할 때 자동 갱신 끄기 | `/local-rag [컬렉션] 컬렉션은 질문할 때 자동 갱신하지 않게 해 줘` |
| 컬렉션 지우기(원본 문서는 그대로) | `/local-rag docs 컬렉션 지워 줘` |

문서를 몇 개 고친 정도는 갱신을 따로 요청하지 않아도 질문할 때 반영됩니다. 바뀐 파일만 다시 처리하므로 오래 걸리지 않습니다.
문서 폴더를 다른 곳으로 옮겼을 때는 새 위치만 알려 주면 됩니다. 내용이 같은 파일은 다시 처리하지 않습니다.

## 설치되는 것

| 구성 요소 | 위치 | 하는 일 |
| --- | --- | --- |
| `local-rag` 스킬 | `~/.copilot/skills/local-rag/` | `/local-rag` 요청을 `rag` 명령으로 처리 |
| `rag` 명령 | 이 폴더의 `bin/` (PATH에 등록) | 폴더 색인, 검색, 갱신, 옮기기, 목록, 삭제 |
| 벡터 DB | 이 폴더의 `indexes/<컬렉션>.db` | RAG로 만든 폴더(컬렉션)마다 파일 하나 |
| 임베딩 모델 | Ollama의 `qwen3-embedding:0.6b` | 문서 조각과 질문을 벡터로 바꿈 |
| 자동 승인 규칙 | VS Code 사용자 설정 | 검색, 목록, 미리보기는 승인 없이 실행 |

## 폴더 구성

```plaintext
키트 폴더/
├── README.md              # 이 문서(사람용)
├── AGENTS.md              # Copilot이 따르는 설치, 반입, 점검 절차
├── USAGE.md               # rag 명령과 설치 도우미 사용법(개발자용)
├── rag.py, bin/           # rag 명령
├── setup/kit.py           # 설치 도우미(설치, 점검, 반입 준비, 복사)
├── skill/local-rag/       # 설치할 때 복사하는 스킬 원본
├── offline/               # 반입 재료(sqlite-vec는 들어 있고, 나머지는 반입 준비 때 받음)
├── tests/selftest.py      # 자체 시험
└── 1-setup.md ~ 4-check-quality.md   # 직접 만들어 보기(강의용)
```

## 주의

- 폴더는 OneDrive, iCloud Drive 같은 동기화 폴더나 다른 프로젝트 폴더 안에 두지 않습니다. 설치할 때 Copilot이 위치를 먼저 확인합니다.
- 키트 폴더를 옮겼거나 다른 PC에서 가져왔다면, 옮긴 폴더를 열고 다시 `설치해 줘`라고 요청합니다.
- 검색으로 찾은 조각은 Copilot 대화에 포함되어 GitHub의 서버로 전달됩니다. Copilot에 보내면 안 되는 문서는 RAG로 만들지 않습니다.
- 지금은 `.md`, `.markdown`, `.txt` 파일만 읽습니다. Word나 PDF 문서는 마크다운으로 변환한 뒤 RAG로 만듭니다.

## 직접 만들어 보기(강의용)

`1-setup.md`부터 `4-check-quality.md`까지는 같은 구성을 Copilot이 처음부터 만들게 하는 단계별 프롬프트입니다.
이 폴더에서 `직접 만들어 보기 폴더를 만들어 줘`라고 요청하면, Copilot이 단계 파일만 담은 새 폴더를 만들어 줍니다.
그 폴더를 열고 입력창에서 `#`으로 파일을 첨부해 "첨부한 파일의 내용대로 진행해 줘"라고 차례로 요청합니다.

| 파일 | 하는 일 |
| --- | --- |
| `1-setup.md` | Python 가상 환경, sqlite-vec, Ollama와 모델 준비, 이 PC의 임베딩 속도 측정 |
| `2-rag-tool.md` | `rag` 명령 만들기, 자체 시험, PATH 등록 |
| `3-skill.md` | `local-rag` 스킬과 터미널 자동 승인 규칙 |
| `4-check-quality.md` | 컬렉션 하나의 검색 품질 점검(필요할 때) |
